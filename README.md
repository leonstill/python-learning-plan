# Python 学习计划

这是一个循序渐进的 Python 编程教程，从零基础开始，覆盖 Python 的核心知识，最终能独立完成小型实战项目。

## 适合人群

- 完全没有编程经验的初学者
- 有其他语言基础、想快速上手 Python 的人
- 需要系统梳理 Python 知识的自学者

## 使用方法

1. **按顺序学习**：章节由浅入深，前面的知识是后面章节的基础，建议不要跳章。
2. **动手练习**：每节末尾有练习题（⭐），每章末尾有综合练习（🌟）。**看懂不等于会写**，请务必动手完成。
3. **控制节奏**：每节约 800 字 + 代码，建议每天学 1~2 节，留出时间消化和练习。

## 🌐 Web 阅读程序

除了直接阅读 Markdown 文件，本项目还提供了一个 Web 在线阅读程序，支持**全文搜索**和**章节跳转**。

### 环境要求

- **Python 3.10+**
- 依赖包：[Flask](https://flask.palletsprojects.com/)（Web 框架）+ [mistune](https://mistune.lepture.com/)（Markdown 渲染）

### 启动方式

**方式一：双击启动（推荐）**

双击项目根目录的 `start.bat`，脚本会自动安装依赖并启动服务。

**方式二：手动启动**

```bash
pip install flask mistune
python server.py
```

启动后，在浏览器中访问：**http://localhost:5000**

### 功能说明

| 功能 | 说明 |
|------|------|
| 📖 **章节阅读** | 首页展示全部 10 章索引，点击进入阅读，支持上一章/下一章导航 |
| 🔍 **全文搜索** | 顶部搜索栏输入关键词（支持中文和英文），实时返回匹配的章节、小节和内容摘要 |
| 🎯 **精准跳转** | 搜索结果点击后直接跳转到对应章节的对应小节位置 |
| 📱 **响应式布局** | 适配桌面和移动端浏览器 |

### 停止服务

在终端中按 `Ctrl+C` 即可停止服务。
