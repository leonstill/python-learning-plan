## 1.1 Python 是什么

Python 是一门**解释型、面向对象的高级编程语言**，由荷兰人 Guido van Rossum 于 1991 年发布。它的设计哲学是**代码可读性优先**——用尽量接近自然语言的方式表达逻辑。

Python 有三个突出优点：

- **语法简洁**：用缩进代替花括号 `{}`，用冒号代替 `begin/end`。代码看起来像可执行的伪代码。
- **生态丰富**：标准库 + 第三方库（PyPI 上有超过 40 万个包）覆盖了 Web 开发、数据分析、人工智能、自动化运维等几乎所有领域。
- **用途广泛**：Instagram 用 Python 做后端，NASA 用 Python 做科学计算，Google 早期大量使用 Python 构建内部工具。

Python 的缺点也很诚实：**运行速度不如 C/Java**。但对绝大多数场景来说，开发效率远比运行效率重要——况且性能敏感的部分可以后续用 C 扩展来解决。

> **一句话**：Python 是让你用最少的代码做最多的事。

## 1.2 搭建开发环境

### 安装 Python

1. 打开 [python.org/downloads](https://python.org/downloads)，下载最新版（3.11+）。
2. 运行安装程序时，**务必勾选 "Add Python to PATH"**——这让你在终端里直接输入 `python` 就能运行。
3. 安装完成后，打开终端（Windows 按 `Win+R` 输入 `cmd`），输入：

```bash
python --version
```

如果看到 `Python 3.x.x`，说明安装成功。

### 两种运行方式

**交互模式**：在终端输入 `python` 回车，出现 `>>>` 提示符，可以逐行输入代码，立刻看到结果。适合试验小段代码。

```python
>>> 1 + 1
2
>>> print("你好")
你好
```

**脚本模式**：把代码写进 `.py` 文件，用 `python 文件名.py` 一次性运行。适合正式程序。

### 用什么写代码

初学者推荐 **VS Code**（免费、轻量、中文支持好），安装 Python 扩展后即可使用。不建议从 PyCharm 入手——功能太多，容易迷失。

## 1.3 第一个程序：Hello, World!

创建文件 `hello.py`，写入以下内容：

```python
# 这是我的第一个 Python 程序
print("Hello, World!")
```

然后在终端运行：

```bash
python hello.py
```

屏幕上会打印出 `Hello, World!`。

### 发生了什么

`print()` 是 Python 的**内置函数**，功能是把括号里的内容显示到屏幕上。`"Hello, World!"` 是一个**字符串**——一串用引号包裹的文本。`#` 开头的那一行是**注释**，Python 执行时会忽略它，它是写给人看的。

### 注释的用法

```python
# 单行注释用井号

"""
三个引号包起来
是多行注释
"""
```

写注释是一个好习惯——一个月后你看自己的代码，没有注释可能就是天书。

## 1.4 变量与数据类型

### 什么是变量

变量就像一个**贴了标签的盒子**：你把数据放进盒子，贴上名字，以后通过名字就能找到它。

```python
name = "小明"     # 变量 name 存了一个字符串
age = 18          # 变量 age 存了一个整数
height = 1.75     # 变量 height 存了一个小数
```

Python 是**动态类型**语言——变量不需要声明类型，赋值时自动判断。

### 基本数据类型

| 类型 | 关键字 | 示例 | 说明 |
|------|--------|------|------|
| 整数 | `int` | `42`, `-7`, `0` | 任意精度，不会溢出 |
| 浮点数 | `float` | `3.14`, `-0.5`, `1e-3` | 小数，注意精度问题 |
| 字符串 | `str` | `"hello"`, `'你好'` | 文本 |
| 布尔值 | `bool` | `True`, `False` | 只有这两个值 |
| 空值 | `NoneType` | `None` | 表示"什么都没有" |

可以用 `type()` 函数查看一个变量的类型：

```python
>>> type(42)
<class 'int'>
>>> type("hello")
<class 'str'>
>>> type(True)
<class 'bool'>
```

### 变量命名规则

- 只能包含字母、数字、下划线，不能以数字开头
- **区分大小写**：`Name` 和 `name` 是两个不同变量
- 不要用 Python 的保留字（如 `if`、`for`、`class`）
- 推荐用下划线命名法：`user_name`、`total_price`

## 1.5 数字与字符串

### 数字运算

```python
a = 10
b = 3

print(a + b)   # 加法 → 13
print(a - b)   # 减法 → 7
print(a * b)   # 乘法 → 30
print(a / b)   # 除法（总是浮点数） → 3.3333...
print(a // b)  # 整除（向下取整） → 3
print(a % b)   # 取余 → 1
print(a ** b)  # 幂运算 → 1000
```

注意：`/` 的结果永远是 `float`，哪怕能整除。想要整数结果用 `//`。

### 字符串操作

```python
s1 = "Hello"
s2 = "World"

# 拼接
print(s1 + " " + s2)     # "Hello World"

# 重复
print(s1 * 3)            # "HelloHelloHello"

# 长度
print(len(s1))           # 5

# 索引（从 0 开始）
print(s1[0])             # 'H'
print(s1[-1])            # 'o'（负数索引从末尾往前数）

# 切片 [开始:结束:步长]
print(s1[1:4])           # 'ell'（含头不含尾）
print(s1[::-1])          # 'olleH'（反转字符串）
```

### f-string：最方便的字符串格式化

```python
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")   # 我叫小明，今年18岁
```

`f"...{变量}..."` 是 Python 3.6 以后最推荐的写法，比 `%` 和 `.format()` 都直观。

## 1.6 输入与输出

### 输出：print()

```python
print("你好", "世界", sep=" | ")   # 你好 | 世界（sep 指定分隔符）
print("第一行", end="；")          # 不换行，以分号结尾
print("还在同一行")
```

### 输入：input()

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

**关键点**：`input()` **返回的永远是字符串**，哪怕用户输入的是数字。做数学运算前需要转换：

```python
age_str = input("请输入年龄：")
age = int(age_str)        # 把字符串转成整数
print(f"明年你{age + 1}岁")

# 也可以一步完成
height = float(input("请输入身高（米）："))
print(f"身高：{height}m")
```

常用类型转换函数：`int()`、`float()`、`str()`、`bool()`。

## 1.7 运算符

### 比较运算符

返回布尔值 `True` 或 `False`：

```python
a, b = 5, 3
print(a > b)    # True
print(a == b)   # False（注意是双等号，单等号是赋值！）
print(a != b)   # True（不等于）
print(a >= 5)   # True
```

### 逻辑运算符

`and`（与）、`or`（或）、`not`（非）：

```python
x, y = True, False
print(x and y)   # False（两边都为 True 才为 True）
print(x or y)    # True（至少一边为 True 就是 True）
print(not x)     # False

# 实际应用
age = 20
print(age >= 18 and age <= 60)   # True（年龄在 18~60 之间）
```

### 赋值运算符

```python
x = 10
x += 3    # 等价于 x = x + 3
x -= 2    # 等价于 x = x - 2
x *= 2    # 等价于 x = x * 2
```

### 运算符优先级

从高到低：`**` → `* / // %` → `+ -` → `== != > <` → `not` → `and` → `or`。记不住就加括号——**括号永远最优先，也最清晰**。

```python
# 这两行等价
result = (a + b) * (c - d)
result = a + b * c - d   # 意欲何为？不易读
```
