## 3.1 列表（list）

列表是 Python 中最常用的容器，用方括号 `[]` 表示，**有序、可修改、元素可重复**。

```python
fruits = ["苹果", "香蕉", "橘子"]
numbers = [1, 2, 3, 4, 5]
mixed = ["hello", 42, True, 3.14]   # 可以混合类型（但通常不这样做）
empty = []                           # 空列表
```

### 常用操作

```python
nums = [10, 20, 30, 40, 50]

# --- 访问 ---
nums[0]         # 10（索引从 0 开始）
nums[-1]        # 50（最后一个）
nums[1:3]       # [20, 30]（切片）

# --- 修改 ---
nums[0] = 99                # [99, 20, 30, 40, 50]
nums.append(60)             # 末尾添加 → [99, 20, 30, 40, 50, 60]
nums.insert(1, 15)          # 在索引 1 处插入 → [99, 15, 20, 30, 40, 50, 60]
nums.remove(30)             # 删除第一个值为 30 的元素 → [99, 15, 20, 40, 50, 60]
popped = nums.pop()         # 弹出末尾元素（可指定索引）
len(nums)                   # 元素个数

# --- 合并 ---
[1, 2] + [3, 4]             # [1, 2, 3, 4]

# --- 检查 ---
20 in nums                  # True
100 in nums                 # False
```

### 列表是"引用"类型

```python
a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表！
b[0] = 99
print(a)       # [99, 2, 3] —— a 也变了

# 正确复制方式
c = a.copy()   # 或者 c = a[:]
```

这是初学者最容易踩的坑：**变量赋值并不复制列表，而是给同一个列表起了个别名**。

### 浅拷贝与深拷贝

`a.copy()` 和 `a[:]` 都是**浅拷贝**——只复制最外层。如果列表里嵌套了列表，内层仍然是共享的：

```python
a = [[1, 2], [3, 4]]
b = a.copy()
b[0][0] = 99
print(a)         # [[99, 2], [3, 4]] —— a 的嵌套列表也被改了！
```

要完全独立复制嵌套结构，需要用 `copy` 模块的 `deepcopy`：

```python
import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0][0] = 99
print(a)         # [[1, 2], [3, 4]] —— 不受影响
```

> 大多数场景浅拷贝就够了。只有嵌套可变结构时才需要 `deepcopy`。

### 排序

```python
nums = [3, 1, 4, 1, 5]
nums.sort()                # 原地排序 → [1, 1, 3, 4, 5]
nums.sort(reverse=True)    # 降序 → [5, 4, 3, 1, 1]

sorted_nums = sorted(nums) # 返回新列表，原列表不变
```

## 3.2 元组（tuple）

元组用圆括号 `()` 表示，和列表很像，但有一个关键区别：**元组不可修改**。

```python
point = (3, 4)
rgb = (255, 128, 0)
single = (42,)        # 单元素元组必须加逗号！
empty = ()
```

### 元组为什么有用

1. **表示固定的数据**：坐标、RGB 颜色、数据库行记录——这些数据的"结构"不该变。
2. **作为字典的键**：元组是可哈希的，列表不是。
3. **函数返回多个值**：本质上返回的是一个元组。

```python
def get_user():
    return "小明", 18, "北京"    # 实际上返回了 ("小明", 18, "北京")

name, age, city = get_user()    # 元组解包
```

### 元组解包（非常好用）

```python
a, b = 1, 2             # 交换值
a, b = b, a             # 一行交换，不需要临时变量

# 用 _ 接收不关心的值
name, _, city = ("小明", 18, "北京")
```

## 3.3 字典（dict）

字典存的是**键值对（key-value）**，用花括号 `{}`，通过键（key）快速查找对应的值（value）。就像现实中的字典——通过一个词（键）查它的释义（值）。

```python
student = {
    "name": "小明",
    "age": 18,
    "scores": [85, 90, 92]
}

print(student["name"])           # "小明"
print(student.get("grade", "N/A"))  # 安全取值，键不存在时返回默认值
```

### 常用操作

```python
info = {}

# --- 增/改 ---
info["name"] = "小红"      # 添加或修改键值对
info.update({"age": 20, "city": "上海"})  # 批量添加

# --- 删 ---
del info["city"]
age = info.pop("age")      # 删除并返回值

# --- 查 ---
"name" in info             # True（检查键是否存在）

# --- 遍历 ---
for key in info:
    print(key, info[key])

for key, value in info.items():   # 同时取键和值（推荐）
    print(f"{key}: {value}")

for key in info.keys():           # 只取键
    print(key)
for value in info.values():       # 只取值
    print(value)
```

### 字典也是"引用"类型

和列表一样，字典赋值不会复制，`b = a` 后改 `b` 也会影响 `a`。

### setdefault：有则取，无则设

```python
word_count = {}
text = "apple banana apple orange banana apple"

for word in text.split():
    word_count.setdefault(word, 0)    # 键不存在时设为 0，已存在则什么都不做
    word_count[word] += 1

print(word_count)   # {'apple': 3, 'banana': 2, 'orange': 1}
```

`setdefault(key, default)` 的逻辑：如果 `key` 已存在，返回它的值；如果不存在，先设为 `default` 再返回。统计计数时特别好用。

## 3.4 集合（set）

集合存储**无序、不重复**的元素，用花括号 `{}`（空集合要写 `set()`，因为 `{}` 是空字典）。

```python
colors = {"红", "绿", "蓝"}
colors.add("黄")             # 添加
colors.add("红")             # 已存在，不会重复添加
print(colors)                # 顺序不确定，每次可能不同
```

### 集合运算（集合的"杀手级"用法）

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a & b      # 交集 → {3, 4}
a | b      # 并集 → {1, 2, 3, 4, 5, 6}
a - b      # 差集 → {1, 2}（a 有但 b 没有的）
a ^ b      # 对称差 → {1, 2, 5, 6}（只在一边出现的）
```

### 去重（最常用场景）

```python
names = ["张三", "李四", "张三", "王五", "李四"]
unique = list(set(names))    # → ["张三", "李四", "王五"]（顺序不定）
```

## 3.5 字符串进阶

在第 1 章我们学了字符串的基本操作，这里补充几个高频用法。

```python
s = "  Hello, Python!  "

# 去除空白
s.strip()          # "Hello, Python!"
s.lstrip()         # 去左边空白
s.rstrip()         # 去右边空白

# 查找与替换
s.find("Python")   # 返回索引位置，找不到返回 -1
s.replace("Python", "World")   # 替换
"py" in s.lower()  # 不区分大小写检查

# 分割与连接（高频使用）
"a,b,c".split(",")       # ['a', 'b', 'c']（按分隔符切开）
"-".join(["a", "b", "c"])  # 'a-b-c'（用分隔符连接）

# 判断
s.isdigit()        # 是否全是数字
s.isalpha()        # 是否全是字母
s.startswith("He") # 是否以...开头
s.endswith("!")    # 是否以...结尾
```

### 字符串是不可变的

```python
s = "hello"
s[0] = "H"    # ❌ 报错！字符串不能原地修改

s = "H" + s[1:]   # ✅ 正确做法：创建新字符串
```

## 3.6 数据结构的选择与转换

| 场景 | 选哪个 |
|------|--------|
| 有序、可修改、需要索引 | 列表 |
| 固定不变的数据 | 元组 |
| 通过名称快速查找 | 字典 |
| 去重、集合运算 | 集合 |
| 文本处理 | 字符串 |

### 互相转换

```python
list("abc")               # ['a', 'b', 'c']（字符串→列表）
tuple([1, 2, 3])          # (1, 2, 3)（列表→元组）
dict([("a", 1), ("b", 2)])  # {'a': 1, 'b': 2}（键值对列表→字典）
set([1, 1, 2, 3])         # {1, 2, 3}（列表→集合并去重）
```

### 一句话总结

- 数据有顺序、要增删改 → **列表**
- 数据有名字、要通过名字查 → **字典**
- 数据不能改 → **元组**
- 数据不能重复 → **集合**
